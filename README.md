# 天气数据可视化

这是一个部署在 GitHub Pages 上的天气数据可视化项目，用于直观展示城市天气指标、温度趋势、湿度变化和风速信息。

## 项目亮点

- 响应式页面布局，适配桌面端和移动端浏览。
- 使用 Canvas 绘制 7 日温度趋势图。
- 展示实时感较强的天气概览卡片，包括温度、湿度、风速和空气质量。
- 提供多个城市的天气数据对比，方便快速查看不同地区的气象差异。
